# APT Dependency Visualizer

Практическая работа по конфигурационному управлению, вариант 14.
Инструмент визуализации графа зависимостей пакетов Ubuntu/apt на Python.

## Текущее состояние

Реализован этап 2: получение индекса Ubuntu, поиск пакета и вывод его
обязательных прямых зависимостей. Информация загружается и разбирается
собственным кодом с использованием стандартной библиотеки Python.
Менеджеры пакетов и сторонние библиотеки получения зависимостей не используются.

Вывод настроек `ключ=значение` сохранён в коммите этапа 1.
Построение транзитивного графа, тестовый граф и применение фильтра относятся
к этапу 3. На втором этапе выводятся все обязательные прямые зависимости.

## Требования и сборка

Нужен Python 3.9 или новее. Внешние библиотеки не требуются.
Сборка не нужна: программа запускается непосредственно интерпретатором.
Все команды ниже выполняются из корня проекта.

## Запуск

URL корня репозитория:

```powershell
.\run.bat --package bash --repository https://archive.ubuntu.com/ubuntu
```

Для такого URL используется индекс Ubuntu 24.04 `noble`, компонент `main`,
архитектура `amd64`: `dists/noble/main/binary-amd64/Packages.xz`.

Чтобы выбрать другой выпуск, компонент или архитектуру, можно указать
полный URL соответствующего файла `Packages`, `Packages.xz`, `Packages.gz`
или `Packages.bz2`. Например:

```powershell
$index = "https://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.xz"
.\run.bat --package bash --repository $index
```

Альтернативный запуск:

```powershell
python src/main.py --package bash --repository https://archive.ubuntu.com/ubuntu
```

Пример результата для `bash` из выбранного индекса:

```text
Прямые зависимости пакета bash:
Pre-Depends: libc6 (>= 2.38)
Pre-Depends: libtinfo6 (>= 6)
Depends: base-files (>= 2.1.12)
Depends: debianutils (>= 5.6-0.1)
```

Справка:

```powershell
python src/main.py --help
```

## Настройки

| Параметр | Назначение | По умолчанию |
| --- | --- | --- |
| `--package` | Имя анализируемого Ubuntu-пакета или тестовой вершины | Обязателен |
| `--repository` | URL корня репозитория, URL Packages или путь при `--test-mode` | Обязателен |
| `--test-mode` | Использовать локальный тестовый репозиторий на этапе 3 | Выключен |
| `--filter` | Подстрока для исключения пакетов при анализе графа на этапе 3 | Пустая строка |

В обычном режиме имя соответствует правилам имён Debian/Ubuntu: минимум
два символа, строчные латинские буквы, цифры и знаки `+`, `-`, `.`.
Первый символ — буква или цифра. В тестовом режиме используются имена
из заглавных латинских букв, например `A`, `B`, `ABC`.

Фильтр проверяется, но на этапе 2 не исключает прямые зависимости из вывода.
Пустая строка разрешена; управляющие символы и значение только из пробелов
запрещены. В URL корня репозитория параметры запроса и фрагмент не допускаются;
для прямого URL индекса адрес сохраняется целиком.

Коды завершения: `0` — успех или справка; `1` — ошибка загрузки или данных;
`2` — ошибка параметров. Сообщения об ошибках направляются в stderr.

## Формат данных и зависимости

Индекс Packages состоит из записей, разделённых пустыми строками.
Каждая запись содержит поля вида `Package: bash`, `Depends: ...` и другие.
Имена полей обрабатываются без учёта регистра, продолжения строк учитываются.
Сжатие gzip, xz и bzip2 определяется по сигнатуре; текст читается как UTF-8.

Из записи выбранного пакета извлекаются поля `Pre-Depends` и `Depends`.
Запятая разделяет обязательные группы, а `|` внутри группы обозначает
альтернативные пакеты. Ограничения версий и уточнения архитектуры сохраняются
в выводе. Выбор альтернатив и проверка установленных версий не выполняются.
Поля рекомендаций, предложений и конфликтов не являются обязательными рёбрами
рассматриваемого графа и в этот вывод не включаются.

Используется конкретный индекс с однозначной записью выбранного пакета.
Если в нём несколько записей этого имени, программа сообщает об этом;
выбор между несколькими версиями одного пакета на этом этапе не выполняется.
Отсутствие пакета и повреждения данных также приводят к понятной ошибке.

Сетевой запрос имеет тайм-аут 15 секунд. Ошибки HTTP, соединения,
распаковки и чтения UTF-8 обрабатываются без трассировки исключения.

## Тестовый режим

```powershell
.\run.bat --package A --repository examples/repository.json --test-mode --filter B
```

Параметры тестового режима и доступность файла проверяются. На этапе 2
команда завершается с кодом `1` и сообщает, что чтение тестового графа
будет добавлено на этапе 3. Сетевого запроса для такого запуска нет.

## Демонстрация ошибок

```powershell
.\run.bat --package Bash --repository https://archive.ubuntu.com/ubuntu
.\run.bat --package bash --repository ftp://example.com
.\run.bat --package A --repository missing.json --test-mode
.\run.bat --package bash --repository https://archive.ubuntu.com/ubuntu --filter " "
.\run.bat --package bash --repository https://archive.ubuntu.com/ubuntu --test-mode=false
```

Отсутствие обязательных значений, неизвестные параметры, недоступный индекс,
отсутствие пакета и некорректные данные также проверяются тестами.

## Тестирование

```powershell
python -B -m unittest discover -s tests -v
```

Тесты используют стандартный `unittest`, подмену HTTP-ответов и временные
файлы. Доступ к интернету для автоматических проверок не требуется.

## Функции командной строки

| Функция | Назначение |
| --- | --- |
| `validate_package` | Проверяет имя с учётом тестового режима |
| `validate_url` | Проверяет схему, наличие узла, порт и символы URL |
| `validate_file` | Проверяет существование и доступность файла |
| `validate_filter` | Проверяет подстроку фильтра |
| `validate_args` | Проверяет все настройки |
| `parse_args` | Описывает, читает и проверяет параметры командной строки |
| `print_dependencies` | Печатает типы и условия прямых зависимостей |
| `main` | Выполняет второй этап и возвращает код завершения |

## Функции чтения репозитория

| Функция | Назначение |
| --- | --- |
| `get_index_url` | Принимает прямой URL индекса или дополняет корень репозитория |
| `download_index` | Получает байты индекса через urllib |
| `decode_index` | Распаковывает данные и декодирует UTF-8 |
| `parse_field` | Разбирает строку поля Packages |
| `iter_package_records` | Читает записи, разделители и продолжения полей |
| `find_package` | Находит единственную запись нужного пакета |
| `extract_dependencies` | Извлекает группы Depends и Pre-Depends |
| `get_direct_dependencies` | Объединяет загрузку, поиск и извлечение зависимостей |
